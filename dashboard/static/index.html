    Help & Documentation

    Guides, architecture overview, and troubleshooting

    📊 Dashboard

    The Dashboard page shows real-time drift metrics: PSI (Population Stability Index), KL Divergence, and MMD p-value across all monitored features. Bars are color-coded: green = stable, orange = warning, red = drifted.

    📦 Models

    View all registered model versions and their baseline feature counts. Each model version has reference distributions registered for drift comparison.

    📡 Monitoring

    Time-series charts show how PSI and KL scores evolve over time. The pipeline status shows real-time health of Kafka → Faust → Alert Engine → Airflow → MLflow.

    🔔 Alerts

    Full history of drift alerts with severity badges. Filter by severity level. Alerts fire when drift scores exceed configured thresholds in the Settings page.

    ⚙️ Settings

    Configure alert rule thresholds for each detector type. Adjust when alerts fire by changing PSI, KL, or MMD thresholds and severity levels.

    🏗️ Architecture

    The system uses a Faust stream processor to analyze tumbling windows of inference data against reference baselines. Three complementary detectors (KL, PSI, MMD) provide defence in depth. Alerts route to Slack/PagerDuty and optionally trigger Airflow retraining DAGs.
